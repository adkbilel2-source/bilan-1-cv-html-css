# Bilan 1 — Créer un CV en ligne

CV de Bilel Adekalon réalisé en HTML et CSS dans le cadre de la formation Développeur Web du Centre Européen de Formation.

## Ouvrir le CV

1. Télécharger le projet avec **Code > Download ZIP**.
2. Extraire toute l'archive.
3. Ouvrir `index.html` dans un navigateur.

Aucune installation n'est nécessaire. La police Lato est chargée depuis Google Fonts et demande une connexion Internet. La police Raleway et les images sont incluses dans le projet.

## Organisation

```text
index.html
assets/
    css/style.css
    fonts/
    images/
```

## Notions utilisées

- Structure HTML sémantique, titres, paragraphes et listes.
- Liens vers une carte, une adresse e-mail, un téléphone et un profil GitHub.
- Feuille CSS séparée, Flexbox et modèle de boîte `border-box`.
- Largeur de 1160 px et centrage horizontal, conformément au sujet.
- Polices Lato et Raleway, couleurs et espacements de la maquette.
- Effets au survol des parcours et de l'icône GitHub.
- Ouverture de l'image de profil en grand, avec un curseur de zoom.
- Titre de page, description, langue du document et textes alternatifs.

Le projet ne contient pas de JavaScript. La largeur fixe peut demander un défilement horizontal dans une fenêtre étroite.

## Choix de contenu

Le parcours reprend les formations et stages indiqués. Les dates et missions incertaines n'ont pas été inventées. Les niveaux de compétences sont des estimations indicatives à 3/5. Une silhouette générique a été choisie pour l'image de profil ; ce choix diffère de la photo personnelle demandée dans le brief.

## Ressources

- Lato et Raleway : Google Fonts. La licence Raleway est conservée dans `assets/fonts/OFL-Raleway.txt`.
- Icône GitHub : Font Awesome Free 6, couleur adaptée en blanc. Licence dans `assets/images/LICENSE-Font-Awesome.txt`.
- Favicon : fourni dans le brief de l'exercice.
- Avatar : formes vectorielles simples.

## Suivi du projet

Une première version a été préparée localement avant l'ouverture de ce dépôt. Les issues organisent ensuite son import et sa documentation sur GitHub. Le code du CV est intégré depuis la branche `import-cv` par une pull request ; la documentation est travaillée sur une branche distincte. L'historique ne reconstitue pas des étapes antérieures à sa création.
